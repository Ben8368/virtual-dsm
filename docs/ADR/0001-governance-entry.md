# ADR 0001：单一协作入口与证据驱动治理

- 状态：已接受
- 日期：2026-10-15

## 背景

项目同时由人类与 AI 工具参与。若每个入口分别保存规则、阶段和能力结论，容易出现状态漂移、重复文档、未经验证的“支持”以及旧计划污染当前任务。

## 决策

- `AGENTS.md` 是 AI 协作唯一入口，工具专属文件只做摘要。
- 每轮先读 `CONTEXT.md` 和 `LESSONS.md`，再按任务路由专题文档。
- 风险、技术债、CI 说明与历史各自只有一个事实源。
- 用无额外运行时依赖的 Python 脚本检查必读预算、链接、路由目标和 ADR 格式。
- 源码改动采用红绿灯审查；CI 固定六个可检查 job 作为仓库级通行灯。
- AI 提交使用工具级 `Co-authored-by` trailer；主作者保持维护者身份。
- 默认不自动提交、推送或发布。

## 后果

好处：上下文更小、事实可追踪、假成功更难进入主线。代价：需要维护文档路由，并在状态变化时更新正确的唯一位置。

## 替代方案

- 每个 AI 工具独立规则：拒绝，规则必然漂移。
- 把所有规则写进一个长入口：拒绝，强制加载成本会持续膨胀。
